# Koch Snowflake — Fractal Geometry & Data Visualization

**Group project · Heinrich Heine University Düsseldorf · 2024**

This project examined the construction and mathematical properties of the Koch snowflake as an example of fractal geometry.

## What we worked on

The project combined mathematical analysis with a Python-based visualization workflow:

- iterative construction starting from an equilateral triangle
- repeated replacement of line segments using the Koch construction rule
- visualization of iterations 0–6
- numerical work with segment lengths and geometric properties
- analysis of perimeter growth
- analysis of the converging enclosed area

## Tools

Python · JupyterLab · NumPy · Matplotlib
